Three Rules That Make It Work

1
Worktree Isolation
Every agent gets its own copy of the repo. No merge conflicts during work. Conflicts only at PR time.
2
Database for Tasks
Linear (not flat files) for task coordination. N agents can read/write simultaneously without collisions.
3
Coordinator Pattern
Nico decomposes and routes. Coding agents code. Research agents research. Separation of concerns.
