# Letta Platform Documentation

## Overview
Letta enables developers to build stateful AI agents with memory and learning capabilities across multiple interfaces.

## Installation
Requires Node.js 18+

```
npm install -g @letta-ai/letta-code
```

## Available Products

**Letta Code** - A memory-focused coding agent accessible via terminal, enabling quick setup in approximately 30 seconds.

**Letta Code SDK** - Toolkit for developing applications that leverage stateful computer use agents.

**Letta API** - Lower-level interface for administering agent memory and contextual information.

## Community & Resources

- **Discord Community** - Connect with other developers and receive support
- **X (Twitter)** - Stay informed about platform updates and announcements
- **ADE (Web Interface)** - Manage and access agents through the browser at app.letta.com

Each product includes quickstart guides for rapid implementation.
