Daily Operations

How the Day Actually Runs

Morning (8 AM)

  1. LettaBot sends Telegram briefing: priorities, overnight PRs, blockers
  2. Nico scans Linear, updates priorities, assigns agents
  3. Vincent reviews, reprioritizes via Telegram or Linear

Work Hours

  1. Nico decomposes tasks into 5-15 min agent-sized issues
  2. Agents pick up issues → branch → work → PR
  3. CI runs tests on every PR automatically
  4. Nico reviews PRs for architecture; Vincent reviews business-critical

Overnight

  1. Runner picks up "overnight-ok" labeled tasks
  2. Agents work in isolated worktrees, open draft PRs
  3. Nothing merges without morning review
  4. LettaBot consolidates day's decisions to memory

Open Questions for CEO

12 Items Requiring Your Decision

These are blockers or decision points extracted from across all sessions and docs. Nothing moves forward on these without your input.

Q1 — BLOCKER
Telegram token rotation — when are you doing this?
Requires BotFather /revoke command from your Telegram. Needs 1Password set up first to store the new token. LettaBot is unstable until this is done.
Q2 — BLOCKER
1Password account — ready to create it? ($2.99/mo)
All secrets (API keys, tokens, credentials) are currently unmanaged. Every agent needs access to secrets. This is foundational.
Q3 — BLOCKER
Obsidian Sync + community plugins — ready to enable?
Phase 0B is 75% done. Need you to sign in, enable Sync, register CLI, and enable community plugins on the M1.
Q4 — DECISION
Linear vs. GitHub Projects for task management?
Linear ($8/user/mo) has automation rules, cycles, bi-directional GitHub sync. GitHub Projects v2 is free but less sophisticated. I recommend Linear. How many seats — just you and Nico, or per-agent?
Q5 — DECISION
Separate GitHub bot accounts per agent, or funnel through lifeosnico-bot?
Separate accounts give clearer audit trails (who did what). Single org account is simpler. I recommend separate for codex-bot, antigravity-bot, copilot.
Q6 — DECISION
Overnight autonomy scope — how aggressive?
Conservative (research/docs only), Moderate (+ tests + small features as draft PRs), or Aggressive (full feature work, draft PRs). I recommend Moderate to start.
Q7 — TIMELINE
Mac Studio timeline?
The delegation engine needs an always-on machine. M1 works for now but Mac Studio is the target for running multiple agents concurrently.
Q8 — ACCESS
Do you have Antigravity IDE access? What level?
Determines whether we include it in Week 1 rollout or defer. It has 1200+ pre-built skills which could accelerate UI work significantly.
Q9 — ACCESS
Do you have OpenAI Codex CLI access?
Requires Copilot Pro+ or Enterprise. Determines our dispatch mechanism for mid-level engineering tasks.
Q10 — DECISION
GitHub org structure — lifeosnico-bot for everything, or separate org for the business?
Clean separation matters for the SaaS product later. Recommend creating a business org (e.g., "lucavo") and keeping lifeosnico-bot for agent infra.
Q11 — CLARITY
What does "working overnight" success look like to you?
Extracted from your Telegram messages. Need a concrete definition: number of PRs? Types of tasks? Zero-failure rate or acceptable failure %?
Q12 — PRIORITY
SaaS portal MVP features — what ships first?
Client onboarding? Project tracking? Invoicing? Quote generation? Need your top 3 features ranked to start the engineering queue once the agent pipeline is live.
